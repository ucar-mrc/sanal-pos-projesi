\# Sanal POS Projesi



Sanal POS tabanlı banka + e-ticaret entegrasyonu (Spring Boot mikroservis projesi).



\## Mimari



\- \*\*bank-service\*\* (8080) → müşteri, hesap, kart, bakiye, transfer

\- \*\*ecommerce-service\*\* (8081) → ürün, sepet, sipariş

\- \*\*pos-service\*\* (8082) → ödeme, komisyon, settlement

\- \*\*eureka-server\*\* (8761) → service discovery

\- \*\*api-gateway\*\* (8083) → routing



\## Teknoloji Stack



\- Java 17, Spring Boot 3.x

\- Spring Data JPA + PostgreSQL

\- Spring Security + JWT

\- OpenFeign, Eureka, Gateway, Resilience4j

\- Flyway, MapStruct, SpringDoc OpenAPI

\- JUnit 5, Mockito, Testcontainers

\- Docker, docker-compose
